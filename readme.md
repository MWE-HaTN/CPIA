# CREST Practitioner Intrusion Analyst (CPIA) Syllabus

**Version:** 8.1 — Released Sep 23
**Exam Format:** Entirely multiple choice — 120 Questions in 120 Minutes
**Level:** Tests knowledge across all 3 subject areas at a basic level, below that of the CREST Registered examination.

---

## 1. Introduction

This syllabus identifies the technical skills and knowledge that CREST expects candidates to achieve success in the CREST Practitioner Intrusion Analyst certification.

## 2. Syllabus Structure

The syllabus is divided into **six knowledge groups** (Appendices A to F), each subdivided into specific skill areas.

---

## Appendix B — Core Technical Skills

|------|--------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------|

| B5   | Application Fingerprinting     | - Determining server types and network application versions from evidential data.<br>- Identification of client software versions from meta-data contained within common document types.<br>- Identification of client/server software versions from service banners, user-agent strings, email headers etc. | MC   |

| B7   | Cryptography                   | - Differences between encryption and encoding.<br>- Symmetric / asymmetric encryption.<br>- Encryption algorithms: DES, 3DES, AES, RSA, RC4.<br>- Hashes: SHA family and MD5.<br>- Message Integrity codes: HMAC.                                              | MC   |

| B9   | File System Permissions        | - File permission attributes within Windows file systems and their security implications.<br>- Analysing registry ACLs.                                                                                                              | MC   |
| B10  | Host Analysis Techniques       | - Listing processes of their associated network sockets (if any).<br>- Assessing patch levels on a Windows host using the command prompt.<br>- Finding interesting files on a Windows host.<br>- Web Servers.                            | MC   |
| B11  | Understanding Common Data Formats | - Candidates are expected to be able to interpret email headers, commenting on the reliability of the information contained within.<br>- Understanding of the information contained within a PKI certificate.<br>- Understanding of various encoding employed for transmission of data (e.g. web and email). | MC   |
